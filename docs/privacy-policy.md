# browzat privacy policy

Last updated 2026-11-23.

browzat connects a browser extension to a server running on the same computer. It processes page content, browser
tabs, cookies, storage, network requests, console messages and files only when the user or their connected AI agent
invokes a corresponding feature. The extension communicates with the local loopback address and does not send this
data to the developer, advertising services or analytics providers.

The local server may save screenshots, PDFs, traces, recordings, storage-state files, oversized tool results and a
metadata-only audit log under the user's browzat data folder. Storage-state files and diagnostic output can contain
private page or session data. The user controls these files and can delete them at any time. The audit log excludes
cookie values, storage values, typed text, passwords, request bodies and agent-supplied code.

browzat does not sell, transfer or use browser data for advertising, credit decisions or profiling. Data is used only
to provide the browser-control and diagnostic features requested by the user. The use of information received from
Google APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Questions and deletion requests can be sent to the repository owner through the support contact on the browzat
project page. Removing the extension and deleting the local browzat data folder removes locally retained data.
